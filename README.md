### Compare and contrast One Hot and Binary encodings

The main difference between One Hot and Binary encoding is the complexity and the number of DFFs being used. For One Hot you will end up using more DFFs but the process is simplified but for binary the process is more complex but requires less DFFs especially as the number of states increases.

### Which method did your team find easier, and why?
